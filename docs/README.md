## 🎯 Product Phases Overview / 产品阶段概览

### Phase 1: The Container (容器) - Current Phase / 当前阶段

**Mission / 使命**: Establish trust through frictionless capture

**Core Philosophy / 核心理念**: Lower barriers, create absolute safety, achieve 90%+ capture conversion rate

**Key Features / 核心功能**:
- ⚡ Instant capture (1.5s launch-to-record) / 极速捕获（1.5秒启动到录制）
- 🎤 Real-time streaming transcription / 实时流式转译
- 📅 Timeline view with context / 带上下文的时间流视图

**Documentation / 详细文档**: [Phase 1 Plan](./phases/phase-01-container.md)

**Status / 状态**: 🚀 In Development / 开发中

## 📝 Documentation Conventions / 文档规范

### Version Control / 版本控制

All documentation follows semantic versioning:

所有文档遵循语义化版本控制：

- **MAJOR**: Complete phase rewrite / 完整阶段重写
- **MINOR**: New section added / 新增章节
- **PATCH**: Minor corrections / 小修正

Example: v1.2.3

示例：v1.2.3

### Update Frequency / 更新频率

- **Progress Tracker**: Daily / 每天
- **Decision Log**: Per decision / 每次决策时
- **Phase Plans**: Weekly / 每周
- **Architecture**: Per major change / 重大变更时

### Contributing / 贡献

When updating documentation:

更新文档时：

1. Keep it bilingual (English/Chinese) / 保持双语（英文/中文）
2. Update table of contents if adding sections / 添加章节时更新目录
3. Mark changes with "Updated: YYYY-MM-DD" / 标记更改日期
4. Cross-reference related documents / 交叉引用相关文档
